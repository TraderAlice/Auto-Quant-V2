## Purpose

This file is the append-only human index of published AutoQuant releases.
Each entry states the bounded product outcome and routes to the completed plan
that owns exact field-trial, test, build, hash, commit, and tag evidence.

It is deliberately not a second current-status page or release checklist:

- [[docs/STATUS]] describes only what the current checkout can honestly do;
- [[docs/design/versioning-and-release]] defines version and publication rules;
- the linked completed plan owns exact proof for that release;
- Git tags remain the immutable version authority.

## Earlier releases

The `0.8.x` line established the repository-root Workspace, Project templates,
strict intake, Factor/Portfolio/RL and fixed-study lanes, immutable evidence,
Studio, Agent orientation, and the first market-data Skill bundle. Its exact
release proof remains in the corresponding completed entries in [[PLANS]] and
the immutable `v0.8.x` Git tags. Historical test counts and transcripts are
not copied into this active documentation surface.
