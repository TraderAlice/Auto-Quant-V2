# Synthetic RL factor-policy fixture

These files are deterministically generated by the `ohlcv-rl-factor-lab`
Project template. They contain alternating, causally observable activity and
intraday regimes so bounded tests can distinguish a state-aware policy from a
global fixed preference.

They are Harness fixtures, not historical market data, alpha evidence, or a
trading recommendation. The Study hashes every byte under `ohlcv/**`; changing
one file changes dataset and Run identity.
