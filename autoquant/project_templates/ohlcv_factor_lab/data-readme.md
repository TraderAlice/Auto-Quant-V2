# Synthetic OHLCV fixture

These files are deterministically generated by the `ohlcv-factor-lab` Project
template. They contain an intentionally discoverable causal volume/next-return
relationship plus noise so the full research loop has a fast known-improvement
test.

They are not downloaded market history and must not be cited as evidence of a
tradable factor. Replacing any file changes the content-locked dataset identity
and intentionally stales Sessions created against the old bytes.
