# Synthetic OHLCV portfolio fixture

These files are deterministically generated by the `ohlcv-portfolio-lab`
Project template. They contain an intentionally discoverable causal
volume/next-return relation so bounded tests can prove a known improvement.

They are Harness fixtures, not historical market data, alpha evidence, or a
trading recommendation. The Study hashes every byte under `ohlcv/**`; changing
one file changes dataset and Run identity.
