# Daum asset file

Use a non-empty JSON array with exactly:

```json
{
  "symbol": "005930",
  "providerSymbol": "A005930",
  "venue": "XKRX",
  "currency": "KRW",
  "assetClass": "equity"
}
```

The provider symbol must be `A` plus six digits. Verify issuer and exact
KOSPI/KOSDAQ listing outside Daum.
